# Onyx Guard Services

Sitio web corporativo de Onyx Guard Services.

## Servicios

- Consultoría de sistemas
- Ciberseguridad
- Soluciones tecnológicas integrales

## Objetivo

Desarrollar un sitio web corporativo seguro, mantenible y escalable.

El desarrollo comenzará localmente y posteriormente se preparará
para desplegarse en una Raspberry Pi y, en una fase posterior,
en infraestructura en la nube.

## Principios

- Seguridad desde el diseño
- Mínimo privilegio
- Defensa en profundidad
- Separación de responsabilidades
- Código documentado
- Arquitectura modular
- Mantenibilidad
- Escalabilidad

## Estructura

onyx-guard-services/
├── backend/
├── docker/
├── docs/
├── frontend/
└── nginx/

## Seguridad

Nunca se deben almacenar en el repositorio:

- Contraseñas
- API keys
- Tokens
- Claves privadas
- Credenciales de bases de datos
- Otros secretos
